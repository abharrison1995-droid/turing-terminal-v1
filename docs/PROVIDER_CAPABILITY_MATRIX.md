# Provider capability matrix

Official provider documentation was last reviewed on **2026-10-01**; implementation details synchronized with the Phase 3.6 configuration on **2026-10-02**. This table separates provider-documented capability from what the Turing adapter consumes. Authentication status is discovered conservatively; installed does not mean authenticated.

| Backend          | Capability                    | Support               | Implementation method and limits                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------- | ----------------------------- | --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| OpenAI Codex CLI | Detection                     | Supported             | `codex --version`; absent executable is reported as missing. The adapter requires version 0.155 or later for managed tool mediation.                                                                                                                                                                                                                                                                                                                                                     |
| OpenAI Codex CLI | Subscription authentication   | Supported             | `codex login status` must report ChatGPT sign-in. Runs force `forced_login_method="chatgpt"`, remove OpenAI API-key and provider overrides from the child environment, and never fall back to API billing.                                                                                                                                                                                                                                                                               |
| OpenAI Codex CLI | Model discovery               | Supported             | Turing starts the authenticated local app server and requests its visible `model/list` catalog. Hidden models are omitted; the model ID must appear in that catalog. Returned account-specific catalog entries are treated as subscription-backed only when the active login is ChatGPT.                                                                                                                                                                                                 |
| OpenAI Codex CLI | Streaming / structured output | Partial               | `codex exec --json` emits JSONL events, which Turing parses for final response text and token counts. Structured reviewer output is validated by Turing; schema-constrained generation is not enabled.                                                                                                                                                                                                                                                                                   |
| OpenAI Codex CLI | Cancellation                  | Supported             | Turing terminates the spawned process tree.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| OpenAI Codex CLI | Tool mediation                | Supported             | `--ignore-user-config --strict-config` plus a read-only host sandbox disables shell, apps, plugins, web search, and multi-agent execution. The run receives only the Turing MCP server with its five broker tools. Codex approves the MCP transport calls, then the Turing broker enforces and records the selected Turing permission mode. Requires Codex CLI 0.155 or later.                                                                                                           |
| OpenAI Codex CLI | Usage telemetry               | Partial               | Turing parses provider-reported input/output tokens when present and records local duration. It does not infer missing token counts or query account allowance/reset information.                                                                                                                                                                                                                                                                                                        |
| OpenAI Codex CLI | Remaining allowance / reset   | Unsupported           | Not queried by this integration.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| OpenCode CLI     | Detection                     | Supported             | `opencode --version`; absent executable is reported as missing.                                                                                                                                                                                                                                                                                                                                                                                                                          |
| OpenCode CLI     | Subscription authentication   | Supported             | OpenCode documents ChatGPT Plus/Pro OAuth and OpenCode Go. Go uses OpenCode-issued credentials, not an OpenAI or Anthropic API key. Turing classifies OpenCode Go and metered/Console routes separately.                                                                                                                                                                                                                                                                    |
| OpenCode CLI     | Model discovery               | Supported             | `opencode models --verbose`; Turing parses exact model IDs, reported variants, and safe capability metadata. A selected variant is passed natively as `provider/model#variant`; the run snapshot keeps the base model and variant separate.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| OpenCode CLI     | Streaming / structured output | Partial               | `opencode run --format json` returns JSON events. This is event structure, not schema-constrained output; Turing validates review/final-gate JSON itself.                                                                                                                                                                                                                                                                                                                                |
| OpenCode CLI     | Cancellation                  | Supported             | Turing terminates the spawned process tree.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| OpenCode CLI     | Tool mediation                | Supported             | Per-run inline config sets all tools to deny and allows only Turing's local MCP broker. The broker enforces project-relative paths and Turing approval policy. Project/global OpenCode configuration is not trusted to grant extra tools; the per-run inline configuration has higher precedence than ordinary project/user config. A machine-managed config may impose stricter policy.                                                                                                 |
| OpenCode CLI     | Usage telemetry               | Partial               | Turing stores local process duration and parses token counts only where JSON events provide recognized fields. OpenCode `stats` can show provider-side session usage but Turing does not query it.                                                                                                                                                                                                                                                                                       |
| OpenCode CLI     | Remaining allowance / reset   | Unsupported           | No documented allowance/reset endpoint is used.                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Claude Code CLI  | Detection                     | Supported             | `claude --version`. Turing's restricted mediation mode requires Claude Code **2.1.248 or later**; older versions must not start a run.                                                                                                                                                                                                                                                                                                                                                   |
| Claude Code CLI  | Subscription authentication   | Supported             | `claude auth status` is parsed in memory for `loggedIn`, `authMethod`, and `apiProvider`; account identifiers are discarded. Runs require `claude.ai` + `firstParty` and the explicit `anthropic-subscription` provider ID. The child environment removes all `ANTHROPIC_*` and `CLAUDE_CODE_USE_*` overrides, preventing API-key, custom endpoint, Bedrock, or Vertex fallback.                                                                                                         |
| Claude Code CLI  | Model discovery               | Partial               | CLI model aliases/full IDs can be selected explicitly; this adapter does not enumerate the complete account catalog.                                                                                                                                                                                                                                                                                                                                                                     |
| Claude Code CLI  | Streaming / structured output | Partial               | `-p --output-format stream-json` streams events. The CLI also documents schema-constrained JSON output, but Turing currently validates reviewer/final-gate JSON after receipt rather than passing a JSON schema to the CLI.                                                                                                                                                                                                                                                              |
| Claude Code CLI  | Cancellation                  | Supported             | Turing terminates the spawned process tree.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Claude Code CLI  | Tool mediation                | Supported             | `--restricted --tools "" --strict-mcp-config` removes built-in command/file tools and loads only Turing's MCP server. Each exposed read/write/delete/build/test/lint request reaches the broker, which checks project scope, secrets, permission mode, and approval status. Requires the documented `--restricted` CLI support.                                                                                                                                                          |
| Claude Code CLI  | Usage telemetry               | Partial               | Turing stores local duration and parses reported token values when present in stream events.                                                                                                                                                                                                                                                                                                                                                                                             |
| Claude Code CLI  | Remaining allowance / reset   | Unsupported           | Not queried by this integration.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Cline CLI        | Detection                     | Supported             | `cline --version`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Cline CLI        | Subscription authentication   | Supported             | ClinePass (`cline-pass`) and Cline usage billing (`cline`) are distinct provider/billing selections. Turing passes the configured provider ID and does not switch lanes on failure. OAuth must be connected before non-interactive execution; missing credentials fail rather than opening a hidden browser or selecting another provider.                                                                                                                                                                                                                                             |
| Cline CLI        | Model discovery               | Unsupported           | The CLI adapter has no documented complete account model-catalog call; explicit model/provider values are required.                                                                                                                                                                                                                                                                                                                                                                      |
| Cline CLI        | Streaming / structured output | Partial               | `--json` streams NDJSON events. This is not a schema-constrained response format; Turing validates structured review/final-gate output itself.                                                                                                                                                                                                                                                                                                                                           |
| Cline CLI        | Cancellation                  | Supported             | Turing terminates the spawned process tree.                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Cline CLI        | Tool mediation                | Supported with limits | Turing launches with `--auto-approve false` and documented desktop approval file IPC. Turing evaluates each request and writes the matching decision file. `CLINE_COMMAND_PERMISSIONS` restricts shell commands and hard-denies selected destructive command forms. Cline does not report each downstream tool's stdout/stderr back through its approval file interface; the operation ledger records authorization and provider-process completion, with that result limitation stated. |
| Cline CLI        | Usage telemetry               | Partial               | Turing stores local invocation duration and parses recognized provider usage fields when the CLI emits them.                                                                                                                                                                                                                                                                                                                                                                             |
| Cline CLI        | Remaining allowance / reset   | Unsupported           | Not queried by this integration.                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

OpenCode documents that use of Claude Pro/Max credentials through OpenCode plugins is prohibited; Turing does not configure that route. ClinePass and Cline usage billing are separate Cline provider IDs and billing lanes; Turing does not automatically switch between them. Subscription Only blocks the Cline usage-billing lane. OpenCode Go and OpenCode metered/Console routes are also separate. Turing cannot inspect or disable provider-side OpenCode overflow billing, so Run Preview reports that status as unverifiable. Connection health relies on CLI/authentication/catalog checks where available and does not send a generation prompt. At run start, available model metadata is snapshotted with the stage for historical display; unavailable models are not migrated automatically.
